# 🎸 AmpCheck

A guitar amp settings app that helps beginners find their perfect tone.

## How to Run

### Option 1: Xcode (Recommended)
1. Open Xcode
2. File > New > Project
3. Choose iOS > App
4. Name it "AmpCheck"
5. Choose Swift and SwiftUI
6. Delete the default ContentView.swift
7. Drag these 3 files into the project:
   - Theme.swift
   - Models.swift
   - AmpCheckApp.swift
8. Press Cmd+R to run

### Option 2: Swift Playgrounds
1. Open Swift Playgrounds on Mac or iPad
2. Create new playground
3. Copy the code from all 3 files
4. Run

## Features
- Search 10 songs with chords and settings
- Select from 8 different amps
- Get compatibility scores
- Visual frequency display
- Haptic mode for hearing-impaired
- Practice mode with chord navigation
- Progress tracking
- Amp condition assessment

## For Swift Student Challenge 2027
This app addresses:
- Beginners quitting due to gear limitations
- Hearing-impaired guitarists who can't hear their tone
- Players with limited dexterity who can't adjust many knobs

## Files
- Theme.swift - All styling (glassmorphism, neumorphism, pastel colors)
- Models.swift - Data models and sample data
- AmpCheckApp.swift - All views and app logic
